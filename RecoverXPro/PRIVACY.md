# RecoverX Privacy Policy (Draft)

Effective date: 2026-09-21

RecoverX is designed to process photographs locally on the Android device. The application does not upload user photos to a RecoverX server as part of its core recovery workflow.

## Data handled

RecoverX can read image metadata and image bytes only when the user grants the required Android permission or explicitly selects a folder/file through the Android system picker. Recovered files are written only to a destination selected by the user or to the app's temporary cache during forensic carving.

## No account required

RecoverX does not require an account for the core recovery features.

## Analytics and advertising

Version 1.0.0 does not include advertising or third-party analytics SDKs.

## User control

Users can revoke Android media permissions from system settings. Folder/file access is granted through Android's picker UI and can be revoked by the user/device.
